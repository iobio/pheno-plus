Phenotyping Web App
01
Launch App
Clinician opens Pheno-Plus from the patient chart. Epic authenticates the app and grants access to the active patient's records.
02
Fetch Notes
Pheno-Plus retrieves available clinical notes from the EHR for the active patient.
03
Select Notes
Clinician selects one or more notes to analyze. Multiple note selection is supported.
04
Extract Phenotypes
Note text is sent to the extraction service. ClinPhen identifies phenotype terms by matching text against a curated HPO vocabulary.
05
Lookup HPO Info
Matched term IDs are resolved to names and definitions locally in the browser — no additional server call.
06
Select Phenotypes
Terms shown highlighted within original note text. Clinician deselects any that are not relevant.
07
Export Phenotypes
Final phenotype list copied to clipboard, ready for use in other tools.
System Layers
Host EHR Environment · Epic
Components
Patient Chart
Active clinical session. Clinician opens Pheno-Plus from the patient chart sidebar. Epic initiates the SMART EHR launch and issues an OAuth 2.0 access token scoped to the active patient and encounter.
SMART EHR Launch OAuth 2.0
FHIR R4 API
Exposes patient data as structured FHIR R4 resources. Clinical notes available as DocumentReference resources, accessed via the scoped bearer token.
HL7 FHIR R4 Read-only
App iframe
Isolated browser context within the EHR that hosts the Pheno-Plus web app. The SMART client library manages token exchange and API access on behalf of the embedded app.
↓ Pheno-Plus runs inside this iframe

Phenotype Extraction Service
ClinPhen Service · iobio backend · Node.js
Receive Request
Shared iobio REST endpoint accepts POST requests containing clinical note text. Also used by genepanel.iobio and clin.iobio.
Express.js Shared iobio service
Extract Phenotypes
ClinPhen matches note text against the HPO synonym lexicon to identify and rank phenotype term mentions. Invoked as a Python subprocess.
Lexicon matching Python subprocess
Return Results
Returns HP term IDs, source text spans, and rank scores as JSON. Label resolution happens client-side in Pheno-Plus — not here.
HP IDs + spans + ranks
